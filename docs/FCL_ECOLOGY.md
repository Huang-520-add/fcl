# FCL 生态圈图鉴（FCL Ecology）v2.4

> **FCL 的本质：推演生态阶的变化。**
> 每一个变量都是生态圈中的一名在册成员；每一行代码都是一次生态事件。
> 变量名不是任意的——**只能用生态圈图鉴中的物种命名**，族群结构（独居/群居）、首领地位、性别与编号都必须体现在名字里。

## 1. 食物链金字塔（营养级优先级）

能量沿营养级**单向流动**：低级被高级捕食，每传递一级仅 20% 能量流向下一级（林德曼定律的传递效率，其余 80% 散失）。分解者回收一切，并通过 CLONE 完成物质循环。

```
         ┌─────────────────────────┐
         │  4级 APEX 顶级掠食者      │  虎 Tiger（独居）  狮 Lion（群居）
         │   吃 3级                  │
         ├─────────────────────────┤
         │  3级 CARNIVORE 食肉动物   │  狼 Wolf（群居）   狐 Fox（独居）
         │   吃 2级                  │
         ├─────────────────────────┤
         │  2级 HERBIVORE 食草动物   │  羊 Sheep（群居）  兔 Rabbit（独居）
         │   吃 1级                  │
         ├─────────────────────────┤
         │  1级 PRODUCER 生产者      │  草 Grass（种群）  藻 Algae（种群）
         └─────────────────────────┘
                      ↕
         ┌─────────────────────────┐
         │  5级 DECOMPOSER 分解者    │  真菌 Fungus（菌落） 杆菌 Bacillus（菌落）
         │  分解一切 → 物质循环       │
         └─────────────────────────┘
```

**捕食优先级铁律**（DEVOURS 校验）：营养级必须恰好相差 1，且捕食者 > 猎物。
狼只能吃羊/兔（2级），不能直接吃草（1级，差 2 级）——生态位错位就是"食性冲突"。

|---|---|---|---|---|
| 1 生产者 | 草 | Grass | 种群（群居无首领） | — |
| 1 生产者 | 藻 | Algae | 种群（群居无首领） | — |
| 2 食草 | 羊 | Sheep | **群居** | 头羊 Alpha_Sheep |
| 2 食草 | 兔 | Rabbit | 独居 | — |
| 3 食肉 | 狼 | Wolf | **群居** | 狼王 Alpha_Wolf |
| 3 食肉 | 狐 | Fox | 独居 | — |
| 4 顶级 | 虎 | Tiger | 独居 | — |
| 4 顶级 | 狮 | Lion | **群居** | 狮王 Alpha_Lion |
| 5 分解 | 真菌 | Fungus | 菌落（群居无首领） | — |
| 5 分解 | 杆菌 | Bacillus | 菌落（群居无首领） | — |

## 3. 族群结构与命名规范

变量名 = `物种_标识`，标识按族群结构决定：

### 3.1 群居物种（狼 / 狮 / 羊）

| 身份 | 格式 | 示例 |
|---|---|---|
| 首领 | `Alpha_<物种>` | `Alpha_Wolf`（狼王）、`Alpha_Lion`（狮王）、`Alpha_Sheep`（头羊） |
| 成员（雄性） | `<物种>_M<编号>` | `Wolf_M1`（1号雄性狼）、`Wolf_M2`（2号雄性狼） |
| 成员（雌性） | `<物种>_F<编号>` | `Wolf_F1`（1号雌性狼）、`Sheep_F2`（2号雌性羊） |

编号从 1 开始，允许跳号（个体死亡/灭绝后编号不回收）。

### 3.2 独居物种（虎 / 狐 / 兔）

| 身份 | 格式 | 示例 |
|---|---|---|
| 个体 | `<物种>_<编号>` | `Tiger_1`（1号虎）、`Fox_2`（2号狐）、`Rabbit_1`（1号兔） |

### 3.3 生产者与分解者（草 / 藻 / 真菌 / 杆菌）

种群与菌落同样用编号个体：

| 身份 | 格式 | 示例 |
|---|---|---|
| 个体/丛 | `<物种>_<编号>` | `Grass_1`（1号草丛）、`Algae_1`（1号藻丛）、`Fungus_1`（1号菌落）、`Bacillus_1`（1号杆菌群） |

### 3.4 命名铁律

1. 物种名必须在册（草→Grass、狼→Wolf……），**生态圈外物种 = 外来物种入侵**，报错 `🌿 外来物种入侵，生态圈不予接纳！`
2. 物种营养级必须与声明类型一致（把 Wolf 声明成 PRODUCER = 分类学混乱）
3. 群居物种必须有 Alpha 首领或 M/F 性别标签；独居物种只能带纯数字编号
4. 违反族群格式 = 身份不明，报错 `⚠️ 族谱登记混乱！`

## 4. 生态指令总览（v2.0 全量）

### 捕食与能量
| 指令 | 生态事件 | 对应能力 |
|---|---|---|
| `INTRODUCE <物种> AS <营养级> WITH <能量> ;` | 引种 | 声明变量 |
| `<捕食者> DEVOURS <猎物> USING <算法> ;` | 捕食（SUM/DIFF/PROD/QUOT） | 四则运算（结果 ×0.2，能量传递效率 20%） |
| `CLONE <目标> FROM <源> ;` | 无性繁殖 | 复制 |
| `SPROUT <生产者> FROM STDIN ;` | 光合捕获 | 输入 |
| `ROT <分解者> TO STDOUT ;` | 分解矿化 | 输出 |

### 生态位评估与逻辑（v2.0 新增）
| 指令 | 生态事件 | 对应能力 |
|---|---|---|
| `ASSESS <A> AGAINST <B> TO <C> ;` | 生态位评估（优势种判定） | 比较 ≥，结果写入 APEX |
| `SYMBIOSIS <A> WITH <B> TO <C> ;` | 互利共生 | 逻辑与 AND |
| `COMPETITION <A> OR <B> TO <C> ;` | 替代觅食路径 | 逻辑或 OR |
| `MIMICRY <A> TO <B> ;` | 拟态伪装 | 逻辑非 NOT |

### 环境驱动（控制流）
| 指令 | 生态事件 | 对应能力 |
|---|---|---|
| `SEASON RAIN { } DRY { }` | 雨季/旱季（湿度二选一） | 条件分支 |
| `MIGRATION <物种> OVER <次数> { }` | 迁徙（能量开方衰减） | 定次循环 |
| `HIBERNATION <物种> UNTIL <A> { }` | 冬眠（直到条件 FULL 才醒，每轮代谢消耗） | **条件循环 while** |
| `MUTATION <物种> { CASE "特征": }` | 基因变异 | 多路选择 |

> **MUTATION 覆盖全部 10 个在册物种**（v2.2）：每个物种都有对应的变异名（Wolf→Wolv、Grass→Grasse、Tiger→Tygre 等），变异概率 1/3，可配合 MATCH() 检测。
| `EXTINCTION <物种> ;` | 灭绝（附内存遗照） | 手动回收 |

### 其他
| 指令 | 生态事件 | 对应能力 |
|---|---|---|
| `GMO ENABLED ;` | 转基因（免能量税，输出打 🧬 标识） | 模式开关 |
| `OBSERVATION: ...` | 科考记录 | 注释 |

## 5. 生态推演示例（狼群捕猎——完整生态故事）

```foodchain
GMO ENABLED ;
BIOME {
INTRODUCE Grass_1 AS PRODUCER WITH 30+35 ;   // 一丛草，能量 65
INTRODUCE Sheep_M1 AS HERBIVORE WITH 0 ;     // 1号雄性羊
INTRODUCE Alpha_Wolf AS APEX WITH 0 ;        // 狼王（布尔判定器）
INTRODUCE Wolf_M1 AS CARNIVORE WITH 0 ;      // 1号雄性狼
INTRODUCE Fungus_1 AS DECOMPOSER WITH 0 ;    // 1号菌落
}
FOODWEB {
Sheep_M1 DEVOURS Grass_1 USING SUM ;         // 羊吃草：能量 65
Wolf_M1 DEVOURS Sheep_M1 USING SUM ;         // 狼吃羊（免税）：65
ASSESS Wolf_M1 AGAINST Sheep_M1 TO Alpha_Wolf ;  // 评估：狼≥羊？→ 狼王 FULL
HIBERNATION Wolf_M1 UNTIL Alpha_Wolf {       // 狼王判定已饱，立刻醒来（循环 0 次）
}
}
DECAY {
Fungus_1 DEVOURS Sheep_M1 USING SUM ;        // 分解者回收残骸
ROT Fungus_1 TO STDOUT ;
ROT Fungus_1 TO STDOUT ;
}
```

**这条食物链的完整叙事**：草被羊啃食 → 羊被狼捕杀 → 狼王判定捕猎成功 → 残骸被真菌分解 → 能量回到土壤（物质循环）。

## 5.5 分解生态学（GC 规则）

分解者是生态圈的"清道夫"，但**它们只分解尸体，不攻击活体**：

1. **活体豁免**：能量 >0 的个体（value≠0）无论闲置多久都不会被分解——活着的生物不会被微生物分解。
2. **尸体分解**：能量耗尽（value==0）且连续 3 条指令未被引用的个体，才会被分解者回收（DECOMPOSE），真实模式下回收时随机阻塞 100ms~1000ms 模拟微生物分解速度。
3. **创造阶段暂停**：BIOME（引种段）是"创造"阶段，不触发分解；MIGRATION/SEASON/MUTATION/HIBERNATION 等生态活跃期同样暂停分解。
4. **顶级豁免**：APEX（顶级掠食者）不受自动回收影响。
5. **手动灭绝**：EXTINCTION 立即回收并打印十六进制"遗照"。

## 6. 生态阶推演哲学

FCL 的每一行代码都是生态事件，每一次运行都是一次生态演替：
- **能量**单向流动（热力学第二定律 → 每级仅 20% 能量传递）
- **物质**循环利用（分解者 → CLONE 回馈低营养级）
- **族群**有社会结构（Alpha 首领统御、雌雄分工、编号世代更替）
- **环境**驱动命运（雨季旱季、迁徙损耗、冬眠蛰伏、基因变异）

代码在吞噬中传递，真理在分解中显现。
